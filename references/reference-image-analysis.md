# 参考图分析与落地协议

用户提供 PPT 截图、网页截图、设计稿或海报时，逐张查看后再生成内容。目标是提取可复用的视觉令牌和页面规律，而不是把截图中的偶然细节误判为完整品牌规范。

## 1. 先识别页面角色与视觉语法

记录每张图承担的叙事角色，例如封面、章节、证据、机制、对比、决策或收束。语义版式名称只可作为辅助标签，不要因为截图像 `cards` 就让后续页面都使用卡片。多张截图要分别标注角色，不要把封面的几何直接套给数据页。

同时记录：

- 可以直接观察到的事实，例如背景色、标题位置、卡片间距、是否有页码。
- 只能推测的规律，例如未展示页面的布局；这些项要标为低置信度并沿用基础预设。
- 无法确认的字体或色值；选择最接近且跨端可用的替代值，不假装精确识别。

## 2. 提取样式令牌

内部使用下列结构即可，不必把分析过程写入交付物：

## 3. 选择渲染策略

### elements（默认）

纯色背景、文字、线条、普通卡片、指标、表格和图表都使用可编辑元素。参考图即使很复杂，也不要因此把本可编辑的文字和数据一起变成图片。

### hybrid（复杂视觉的默认降级）

只把没有可靠 PPT 等价物的局部做成 SVG/PNG，例如摄影、3D、手绘、水墨、颗粒、纸张纹理、复杂渐变或插画。图片中不要包含必须准确显示的标题、正文、数字或图表标签；这些内容另用可编辑元素叠加。

若需要生成图片，提示词描述画面与留白位置，并明确 `no text, no letters, no numbers, no watermark`。生成后把实际资源路径写入 `path` 或 `data`，不能只留下 `prompt`。

先通过当前 agent 的本地技能清单确认可调用的生图能力，再按 [按需生图](image-generation.md) 执行。精确复刻时优先使用参考图中的原始照片、产品图或纹理；为新内容延展风格时，可生成相同视觉语言的局部插画，并保持原生文字与数据独立。

### full-raster（仅显式接受时）

只有用户明确把“视觉像素还原”置于“可编辑、可访问、文字可靠”之上，并接受整页不可编辑时，才使用整页图片。中文或关键数字不得依赖图片生成模型准确书写。

## 4. 复刻模式：把一张参考页做成对齐的可编辑页

只在用户明确要求“还原这页 / 照这张做一页”时启用，且只对该页生效；其余页面仍按 1–3 节重新构图。目标是几何与信息层级对齐，不是把截图变成图片。

**量**

- 把参考图缩放到 1280×720，叠 80px/45px 网格并标坐标数字，导出后读图取坐标；换算统一用 `画布 = 原图 × 1280 ÷ 原图宽`。
- 色值一律在元素内部取像素（工具不限：sharp / GDI+ / ImageMagick），多点确认渐变或半透明，不要目测。
- 结构沿行/列扫描色差边界，量出柱体上下沿、卡片矩形、色带与分隔线。数据图形**先按“总量→总高”反推比例尺再标分段**；分段间的白缝要收窄；虚线别并进色块。

**排**

- 文字先用 `0.55 × fontSize × 字符数` 估宽（中文按 1.0）放到扫描位置。
- 必做校准：把自渲染结果与参考图在同一区域取暗像素包围盒（min/max x/y）对比。品牌字体常让拉丁文字窄 10–20%，按实测比值调 `fontSize`；同一行的多段文字分别调起点 `x`。
- 元素数组顺序即 z 序：压着照片或色块的文字要放在图片**之后**，否则会被盖住。
- 照片、纹理从参考图裁出，这是唯一该标 `rasterized` 的部分；裁到压在图上的文字时，用相邻背景条克隆覆盖（硬克隆 + 缩小放大淡化接缝）。图标用 `shape-circle`/`shape-rect`/`shape-path` 重画，保持可编辑。

**验**

- 用同一份编译产物出校对图，与参考图做 50% 叠加：形状错位会直接变成重影；文字按上面的包围盒数字比对。
- 逐项写明差异（字体替换、图标重画、取不到的确切色值），不把“很像”说成“像素一致”；最终以 PowerPoint/WPS 打开为准。
- 色值进 `theme`、重复视觉进 `styleClasses`；有意叠放处写 `allowOverlap: true`，别让真实告警被淹没。
- 反例：整页贴图；肉眼报色值坐标；把字号撑到溢出来“凑像”；复刻一页就把整套 deck 套成这版式。

## 5. 落地检查

- 色板、圆角、边框、页面边距和固定装饰在各页保持一致。
- 截图裁切、阴影或透视造成的颜色偏差不应变成新令牌。
- 一张截图没有展示的页面角色继续使用基础预设，不凭空发明规则。
- `build_all` 报告里的 `failed` 和 `skipped` 必须为 0；局部图片应明确显示为 `rasterized`。
- 与截图比较时优先检查信息层级、相对位置和节奏；字体替换与原生图表的小幅差异单独记录。

## 示例

参考图是深蓝底、金色细线、白色衬线标题，且只有封面：选择最接近的基础样式，覆盖背景、强调色和字体；只把“强留白、左侧标题、金色细线、冷暖比例”作为高置信度视觉语法。内容页依据内容重新构图，而不是推断所有页面都必须深色或使用相同左右分栏。
