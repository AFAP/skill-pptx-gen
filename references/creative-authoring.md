# AI 自由创作工作流

需要创建新 deck、把长文档转为演示文稿，或根据参考图扩展出多页内容时读取。本文件决定 AI 如何创作页面；转换细节分别见 `webslide.md` 与 `dsl-schema.md`。

## 核心分工

- AI 决定页面要表达什么、读者先看到什么、信息之间是什么关系，以及使用怎样的视觉隐喻。
- DSL 只负责把创意准确描述为可检查的对象，不替 AI 选择整页模板。
- Konva 预览和 PptxGenJS 导出都消费编译后的 primitive scene；正式审阅以 Konva 预览为准，不以原始 HTML 的偶然效果为准。

不要从 `cards`、`metrics`、`comparison` 中先选一个再塞内容。先判断内容关系，再决定是否值得自由构图。

## 页面计划

写 deck 之前，用很短的结构规划每页：

```json
{
  "role": "evidence",
  "message": "出货量第一尚未转化为利润领先",
  "evidence": ["中国市场份额 10.6%", "2026E PE 约 137 倍"],
  "visualMetaphor": "两条高度不一致的阶梯",
  "hierarchy": "市场地位为主，盈利约束为反差",
  "authoring": "creative-dsl",
  "exportPlan": "原生文字、形状和图表"
}
```

`visualMetaphor` 不是装饰名称，而是内容关系的图形表达。没有合适隐喻时，用清晰的编辑式排版、图表或表格，不强行画图。

## 内容关系到视觉语言

| 内容关系 | 可考虑的视觉语言 |
| --- | --- |
| 正反力量、增长与约束 | 拉力、天平、双轨、分裂画面 |
| 因果链、价值链 | 路径、接力、传动链、流体管线 |
| 能力层级、证据递进 | 阶梯、塔、剖面、同心层 |
| 业务组合、市场构成 | 光谱、带状分区、环形构成、堆叠条 |
| 时间变化 | 轨迹、坡度、里程碑、阶段带 |
| 风险与不确定性 | 故障树、热力图、压力区、断裂点 |
| 平台和生态关系 | 星系、网络、核心与卫星、接口图 |
| 一个关键数字 | 大数字与尺度参照，避免再包一层卡片 |

同一种关系也可以有多种表达。根据受众、内容密度和上下页节奏选择，不把表格中的每一行都画成图。

## 模式选择

### Creative DSL

适合关键观点、机制、关系、流程和精确曲线。可直接组合 primitive，并用以下源级宏减少重复：

- `styleClass` 复用视觉属性。
- `group` 使用相对坐标组织一组对象。
- `repeat` 用数据批量生成节点、标签或刻度。
- `anchor` 相对已有元素定位。
- `connector-s`、`connector-elbow`、`arc-segment` 表达曲线和轨道。

这些宏会在颜色解析和渲染前消失，因此不会削弱两端一致性。

### Creative WebSlide

适合 AI 能用 Flex/Grid 更快表达的编辑式构图、杂志式排版和参考图复刻。规则：

1. 页面固定 1280×720。
2. 共享 CSS 负责整套视觉语法，每页 DOM 负责独特结构。
3. 需要进入 PPTX 的叶子节点显式写 `data-ppt`。
4. 转换后检查 Konva 预览，不把浏览器原页当成最终保证。
5. 没有 PPT 原生等价物的装饰只做局部图片；文字和数据另行叠加。

### Compact

适合目录、章节、低价值过渡、普通清单和极短交付。Compact 是创作效率工具，不是默认审美。若三页以上连续使用同一语义版式，应重新判断是否有页面值得升级为 Creative。

## 信息丰富而不拥挤

重要内容页通常包含三个层次：

1. **结论**：读者离开页面时应记住的判断。
2. **证据**：数字、比较、时间、来源或关键机制。
3. **意义**：该证据改变了什么判断、选择或风险。

三者不必都成为正文段落。意义可以是图上的注释、方向标、阈值线或短结论。详细数据和引用放在 speaker notes；不要把信息丰富误解为增加卡片数量。

## 视觉语法，不是页面模板

主题或参考图应约束以下内容：

- 字体层级和数字尺度。
- 主色、强调色及色彩占比。
- 留白和内容密度。
- 圆角、切角、描边与阴影强度。
- 直线、折线、S 曲线或轨道的使用偏好。
- 图片裁切、明暗和边缘处理。
- 图表网格线、标签和系列颜色。

主题不规定标题必须在哪、页面必须有几列。复用这些视觉规则，同时让每一页的几何结构响应内容。

## 参考截图

先提取高置信度视觉语法，再为新内容重新构图。只有用户明确要求逐页复刻时才复制几何。单张封面截图不能推出所有内容页都应使用相同左右分栏。

如果截图包含复杂背景：

- 将无文字的背景、纹理或插画作为局部图片。
- 标题、数字、表格和图表继续使用原生对象。
- 不依赖图片模型生成准确文字或数据。

## 创作自检

- 缩略图状态下，各页是否有不同轮廓，而整套仍像一个系列。
- 每页第一视觉焦点是否对应最重要的信息。
- 数据页是否真的回答一个问题，而不是只展示数据存在。
- 连线是否表达关系，还是仅仅增加装饰。
- 装饰图片能否在不损害信息的情况下删除；若能，考虑删掉。
- 页面是否因担心溢出而过度删减到只剩标题和几个词。
- 所有事实、预测、假设和推断是否区分清楚。

## 示例定位

- `南京埃斯顿深度研究报告-29页展示版` 是工程覆盖案例，用于验证版式、图表、表格和路径能力。
- `南京埃斯顿深度研究报告-AI创意版` 是创作案例，用于展示内容驱动构图、组合宏和页面节奏。

两类案例都需要，但不要用工程覆盖案例代表 AI 的创作上限。
